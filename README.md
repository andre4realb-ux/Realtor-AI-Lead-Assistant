# Realtor AI Lead Assistant

An AI-powered real estate lead assistant that engages website visitors, qualifies buyers, sellers, and renters, captures contact details, and organizes enquiries for agent follow-up.

## Features

- AI-powered real estate conversations
- Buyer, seller, renter, and investor qualification
- Captures budget, location, property details, timeline, and financing
- Captures name, phone, and email
- Lead scoring: HOT, WARM, or NURTURE
- Structured lead capture
- Agent contact request form
- Mobile-friendly web interface

## Technology

- Python
- Flask
- Google Gemini API
- HTML / CSS / JavaScript
- JSON-based lead storage
